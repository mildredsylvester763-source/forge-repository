# TQ-039: Visual regression with perceptual diffing

## Behaviour

- Diffs are computed per pixel with perceptual luminance weighting: a pixel differs when 0.299*|dr| + 0.587*|dg| + 0.114*|db| exceeds the threshold scaled to 255 (default threshold 0.1).
- Ignore regions mask rectangles of pixels out of both the difference count and the denominator; diffPercent is differing pixels among comparable pixels, rounded to two decimals.
- Images are grids of #rrggbb hex pixels. Malformed input is refused by name: visual-image-missing:label, visual-dimension-invalid:label:axis, visual-pixels-invalid:label, visual-pixel-invalid:label:i, visual-size-mismatch:w1xh1:w2xh2, visual-threshold-invalid:x, visual-regions-invalid, visual-region-invalid:i.

## Where it lives

src/modules/test-quality/engine/visual-regression.ts (pure), reached through POST /v1/test-quality/visual/diff.

## Limits, stated plainly

Hex grids stand in for decoded bitmaps; the diffing law is the real one but the pixels arrive pre-encoded. Layout shifts are a size mismatch, not a diff.
