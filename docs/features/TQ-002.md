# TQ-002: Web browser testing

## Behaviour

- The web platform supports exactly ten actions: click, type, scroll, drag, hover, key, upload, navigate, wait, assert. A step outside the vocabulary is refused by name, never guessed.
- Unknown platforms are refused with platform-unknown:x; an empty action with platform-action-missing; an action no platform knows with platform-action-unknown:x; an action another platform knows with platform-action-unsupported:action:web.

## Where it lives

src/modules/live-testing/engine/platform-capability.ts (pure), enforced on every recorded step through POST /v1/live-testing/sessions/steps.

## Limits, stated plainly

The engine is the vocabulary, not a browser driver. It checks what the AI tester is allowed to do on web; actually driving a real browser is the agent runtime's job.
