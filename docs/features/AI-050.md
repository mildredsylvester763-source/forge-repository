# AI-050: Bring-your-own-key per workspace

## Behaviour

- Keys are never stored and never echoed: the response carries only a fingerprint (byok_ prefix) and the key length. Short or malformed keys are refused (byok-invalid-key).
- Keys live per user, so two users can bring the same key and get the same fingerprint without ever seeing each other's registration.

## Where it lives

src/modules/ai-training/engine/model-gateway-engine.ts (pure), reached through POST /v1/ai-training/gateway/byok.

## Limits, stated plainly

- The raw key exists only in the request moment. There is no vault; losing the key means bringing it again.
