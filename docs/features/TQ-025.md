# TQ-025: Cross-device handoff

## Behaviour

- An acting session (running or paused) hands off to another device from the catalog. The target device replaces the session device profile with its full catalog spec; the session status never changes.
- The first device is staged automatically, even across platforms: initial true, fromDevice null, resume automatic.
- Later handoffs between different platforms require manual resume; same platform handoffs stay automatic. Handing off to the current device is refused.
- Refusals are named: handoff-status-missing, handoff-state-invalid:X, handoff-to-missing, handoff-device-unknown:X, handoff-same-device, handoff-platform-missing.

## Where it lives

src/modules/live-testing/engine/cross-device-handoff.ts (pure), POST /v1/live-testing/sessions/handoff (owner only).

## Limits, stated plainly

The handoff swaps the profile and records a step; it does not move live process state. Goal preservation is declared, not serialized.
