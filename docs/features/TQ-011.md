# TQ-011: Session chat messages

## Behaviour

- The owner and an active participant with the messages capability can post one message into the session transcript. The body is trimmed and capped at 2000 characters.
- Refusals are named: session-not-found:x for strangers and inactive participants, collaboration-capability-denied:role:messages for observers without the capability (owner and tester have it), message-empty for whitespace-only bodies.

## Where it lives

src/modules/live-testing/live-testing-service.ts (postMessage), POST /v1/live-testing/sessions/messages.

## Limits, stated plainly

Messages are a stored transcript, one role per side. There is no streaming, edit or deletion of sent messages.
