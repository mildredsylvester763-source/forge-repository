# AI-044: Instant rollback to a previous model version

## Behaviour

- Rollback targets a version that is actually in the served set; unknown targets are refused by name (rollback-unknown-version). Nothing outside the served set can be rolled to.
- The result records from and to versions, is instant, and is fingerprinted (rb_ prefix) so the rollback itself is auditable later.

## Where it lives

src/modules/ai-training/engine/model-operations-engine.ts (pure), reached through POST /v1/ai-training/ops/rollback.

## Limits, stated plainly

- Instant means the plan flips immediately. Requests already in flight when the rollback lands are not rewound.
