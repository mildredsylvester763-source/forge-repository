# TQ-014: Builtin test personas

## Behaviour

- Six builtin personas: impatient-user, low-vision-user, motor-impaired-user, new-user, power-user, screen-reader-user. Each is a deterministic trait vector (familiarity, patience, exploratory, accessibility needs, keyboard only, pacing); lookups always return a fresh copy so callers cannot mutate the catalog.
- The checklist derives from the vector: everyone runs the smoke critical path; unfamiliar users add onboarding, empty states and help affordances; exploratory users add edge cases and error paths; accessibility needs add keyboard, focus, label and contrast checks; keyboard-only users add a trap scan; impatient users add loading feedback.
- Pacing bands: 1.5 above 70 patience, 1.0 above 40, else 0.75. Refusals are named: persona-missing, persona-unknown:x.

## Where it lives

src/modules/live-testing/engine/persona-profile.ts (pure), catalog at GET /v1/live-testing/personas; personas are chosen by name at POST /v1/live-testing/sessions.

## Limits, stated plainly

Personas shape what a session checks and how fast it prefers to go. They do not change engine law; every persona runs under the same refusals.
