# AI-069: Reference search for creative work

## Behaviour

- A pinned catalog of twelve reference assets across six media (pose, anatomy, environment, texture, moodboard, color) and four licenses (cc0, free, public-domain, owned).
- Queries AND-match over title plus tags, case-insensitive, with optional medium and license filters. Empty results are honest, not errors.
- Refusals are named: reference-query-missing, reference-medium-unknown, reference-license-unknown.

## Where it lives

src/modules/search-integrity/engine/reference-search.ts (pure), reached through GET /v1/search-integrity/references/media, GET /v1/search-integrity/references/licenses and POST /v1/search-integrity/references/search.

## Limits, stated plainly

The catalog is hand-pinned, so it is small by design. There is no image similarity and no thumbnail fetching; this finds references by words, the way a moodboard's labels do.
