# TQ-005: Desktop app testing

## Behaviour

- The desktop platform supports exactly nine actions: click, type, key, hover, drag, menu, window-resize, file-dialog, assert. Windows, menus and file dialogs are the desktop's native surface.
- Unknown platforms are refused with platform-unknown:x; an empty action with platform-action-missing; an action no platform knows with platform-action-unknown:x; an action another platform knows with platform-action-unsupported:action:desktop.

## Where it lives

src/modules/live-testing/engine/platform-capability.ts (pure), enforced on every recorded step through POST /v1/live-testing/sessions/steps.

## Limits, stated plainly

The engine validates the desktop vocabulary. Native OS automation (real window handles, real dialogs) lives with the agent runtime, not here.
