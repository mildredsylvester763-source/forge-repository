# AI-024: Regression ship gates

## Behaviour

- A model ships only through its gate: every measured metric needs a threshold, every threshold must be measured, and every failure is named (gate-below-minimum, gate-regression).
- Regression checks a baseline against a maximum allowed drop; drops round to a millionth.
- Multiple failures are joined with a semicolon and a space, all named, none dropped; invalid thresholds are refused: gate-invalid-minimum, gate-incomplete-regression, gate-invalid-baseline, gate-invalid-max-drop, gate-invalid-score, gate-missing-threshold, gate-unmeasured-metric.

## Where it lives

src/modules/ai-training/engine/eval-gate-engine.ts (pure), reached through POST /v1/ai-training/eval/gate.

## Limits, stated plainly

The gate sees declared numbers, not measurements it takes itself. Empty metrics and empty thresholds pass; a gate over nothing is no gate at all, which callers must not mistake for approval.
