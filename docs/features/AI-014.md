# AI-014: Run lifecycle and checkpoint resume

## Behaviour

- States are planned, running, paused, succeeded, failed and canceled; only the pinned transitions are legal, and every illegal jump is refused by name: run-illegal-transition, run-unknown-state.
- Only a paused run with a checkpoint inside the plan resumes; refusals named: resume-not-paused, resume-no-checkpoint, resume-checkpoint-invalid, resume-checkpoint-past-plan.
- Checkpoints carry step, monotonic sequence and loss; recording one outside a running run is refused with run-not-running.

## Where it lives

src/modules/ai-training/engine/training-run-engine.ts (pure), reached through POST /v1/ai-training/runs/transition and POST /v1/ai-training/runs/checkpoint.

## Limits, stated plainly

The state machine trusts the caller to move runs; there is no scheduler. A run left running forever is valid to the engine.
