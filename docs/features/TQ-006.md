# TQ-006: Session detail and run listing

## Behaviour

- A signed-in user lists their own sessions (newest first, at most 50) through GET /v1/live-testing/sessions and reads one session's full picture through POST /v1/live-testing/sessions/get: the session row plus step count, message count and all findings.
- Sessions belong to exactly one owner. Anyone else, including a stranger, gets the same uniform refusal session-not-found:x, never a leak of the session's existence.

## Where it lives

src/modules/live-testing/live-testing-service.ts (getSession, listSessions), routes in src/modules/live-testing/routes.ts.

## Limits, stated plainly

Listing is capped at 50 sessions per call; there is no search or pagination cursor yet.
