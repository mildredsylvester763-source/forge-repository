# TQ-020: Real device farm: many devices, OS versions, screen sizes

## Behaviour

- GET /v1/live-testing/devices serves a catalog of twelve named devices across four platforms: web browsers, android phones, iphones and ipads, and desktop machines.
- Every device carries a fixed spec: device name, platform, a lowEnd flag and a cpuThrottle factor (low-end hardware throttles at 4, everything else at 1).
- The route also serves the six pinned network conditions used with the devices.
- The route requires a signed-in user.

## Where it lives

src/modules/live-testing/engine/device-profile.ts (pure) through src/modules/live-testing/routes.ts, GET /v1/live-testing/devices.

## Limits, stated plainly

This is a simulated farm. It does not rent or drive physical phones, does not install real OS versions, and does not read real screen sizes from hardware. The real device farm with physical phones stays flagged as risky in PROGRESS and is not built here.
