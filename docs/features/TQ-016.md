# TQ-016: Session findings feed

## Behaviour

- The owner and an active participant with the findings capability report findings against a running record: a severity from 1 to 5, a trimmed non-empty title, optional reproduction steps, an evidence object and an optional suspected commit (hex, 7 to 40 characters).
- Every reported finding emits a FindingReported event. The latest finding feeds the bug report assembly.
- Refusals are named: session-not-found:x, collaboration-capability-denied:role:findings, finding-severity-invalid, finding-title-missing, finding-commit-invalid.

## Where it lives

src/modules/live-testing/live-testing-service.ts (reportFinding); POST /v1/live-testing/sessions/findings.

## Limits, stated plainly

Evidence is stored as an opaque object. The service keeps its shape honest but does not interpret screenshots or logs.
