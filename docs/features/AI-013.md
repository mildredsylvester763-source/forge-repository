# AI-013: Deterministic training plans

## Behaviour

- A plan turns a frozen snapshot into epochs (default 3), batch size (default 32), step count (items per batch, rounded up, times epochs) and estimated cost; all pinned, all reproducible.
- A plan over budget is refused loudly, never trimmed: plan-budget-refused names both the cost and the budget.
- Refusals named: plan-no-fingerprint, plan-no-items, plan-invalid-epochs, plan-invalid-batch-size, plan-invalid-cost, plan-no-budget.

## Where it lives

src/modules/ai-training/engine/training-run-engine.ts (pure), reached through POST /v1/ai-training/runs.

## Limits, stated plainly

Cost per step is declared by the caller; the engine does not verify it against real billing. Steps are arithmetic, not measured throughput.
