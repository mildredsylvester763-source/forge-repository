# TQ-018: One-click test conversion

## Behaviour

- A finished session converts into one deterministic replayable test case: a name drawn from the first goal task, falling back to the title, falling back to Converted session; one case step per recorded step (the trimmed action plus the target when present); a fixed expectation, All n steps replay in the same order.
- Step sequences must be contiguous from 1 and actions non-empty.
- Refusals are named: conversion-empty, conversion-step-seq-broken:n, conversion-step-action-empty:n.

## Where it lives

src/modules/live-testing/engine/test-conversion.ts (pure), reached through POST /v1/live-testing/sessions/convert.

## Limits, stated plainly

Conversion is structural: it replays the recorded action lines in order. It does not infer assertions beyond the recorded ones.
