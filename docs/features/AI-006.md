# AI-006: Dataset versioning and lineage

## Behaviour

- Building the same name again parents to the latest version: changed content becomes version plus one; identical content is refused with dataset-unchanged-content.
- Every snapshot records parentSnapshotId and parentVersion; a caller-supplied parent must exist or the refusal is dataset-parent-not-found.
- Soft-deleted assets drop out of new snapshots while old snapshots stay frozen evidence.

## Where it lives

src/modules/ai-training/engine/dataset-snapshot.ts (pure) plus service lineage logic; POST /v1/ai-training/datasets, POST /v1/ai-training/datasets/list (name filter) and POST /v1/ai-training/datasets/get.

## Limits, stated plainly

Parent fingerprints are reconstructed from stored membership; a hard-deleted asset row makes the parent fall back to its stored fingerprint. Versions are per name, not global.
