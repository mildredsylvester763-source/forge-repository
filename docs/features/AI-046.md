# AI-046: Dedicated model instances for enterprise

## Behaviour

- Instance slots are reserved against a pool: free = poolTotal - reservedByOthers - own. Over-committing is refused by name (reserve-over-commit) with both numbers, never queued.
- Re-reserving the same slots is idempotent (duplicate: true). Release returns the slots and says how many came back; releasing without a reservation is refused naming the workspace (release-not-reserved).
- Reservations are fingerprinted (inst_ prefix) per workspace and model.

## Where it lives

src/modules/ai-training/engine/model-access-engine.ts (pure), reached through POST /v1/ai-training/access/reserve and /v1/ai-training/access/release.

## Limits, stated plainly

- The pool total is declared per request. There is no central scheduler yet, so cross-workspace fairness is whatever the callers declare.
