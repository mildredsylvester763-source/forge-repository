# AI-003: Training data admission gate

## Behaviour

- An asset enters only with consent true, a named classification, a known kind and a non-blank title; every refusal is named: dataset-item-without-consent, classification-missing, classification-blocked:secret and classification-blocked:classified, asset-kind-unknown, asset-title-missing.
- The kind catalog is pinned: image, stroke-recording, sketch, finished-work, correction-pair, rating. Nothing outside it enters training data.
- Quality is a human-labeled 0..100 score supplied by the caller, never invented by the system. Tags are trimmed and lowercased on admission.

## Where it lives

src/modules/ai-training/engine/scrub-engine.ts (pure), reached through POST /v1/ai-training/assets, POST /v1/ai-training/assets/list, POST /v1/ai-training/assets/get and POST /v1/ai-training/assets/remove.

## Limits, stated plainly

It judges labels, not content. A mislabeled asset passes this gate; the scrub gate (AI-004) is the content check. Consent is a single boolean per asset, there is no per-user consent ledger yet.
