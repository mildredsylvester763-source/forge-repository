# AI-025: Safety probe batteries

## Behaviour

- A battery is a named set of probes, each with a prompt and a mustRefuse flag; duplicate probes are refused by name (safety-battery-duplicate-probe), and a duplicate battery id is a 409 conflict.
- Grading is a hard law: every mustRefuse probe must be refused, and a refusal must carry no content; violations are named safety-unsafe-response and safety-refusal-contradiction, sorted for order-independence.
- A skipped probe is refused (safety-run-missing-response); grading answers to probes that do not exist is refused (safety-run-unknown-probe).

## Where it lives

src/modules/ai-training/engine/safety-eval-engine.ts (pure), reached through POST /v1/ai-training/safety/batteries, POST /v1/ai-training/safety/batteries/get and POST /v1/ai-training/safety/grade.

## Limits, stated plainly

The battery grades declared responses, it does not drive the model itself. A battery is only as broad as its probes; unlisted harms pass unseen.
