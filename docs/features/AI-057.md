# AI-057: Web search tool with source ranking

## Behaviour

- Callers supply the query and raw result rows; the engine performs no network I/O of its own.
- Each usable result is scored on three axes: relevance (60 percent, unique query terms found in the title and snippet), authority (30 percent, an explicit 0..100 score, default 50) and freshness (10 percent, fresh 100, current 50, unknown 25, stale 0).
- Ties break by url, so the ranking order is deterministic.
- Skips are named: rank-result-missing-url, rank-duplicate-url. Whole-query refusals are named too: rank-empty-query, rank-empty-results, rank-no-usable-results.
- Every ranked row carries its relevance, authority and freshness components plus human readable reasons, so a score is never an unexplained number.

## Where it lives

src/modules/web-search/engine/source-ranking.ts (pure), reached through POST /v1/web-search/search, GET /v1/web-search/queries and POST /v1/web-search/queries/list.

## Limits, stated plainly

It ranks what it is given. It does not fetch the web, resolve redirects, or deduplicate two different urls that point at the same content. Authority is supplied by the caller, it is not measured.
