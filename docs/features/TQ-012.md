# TQ-012: Goal parsing into a task list

## Behaviour

- A plain-language goal splits on newlines, semicolons and the word then into at most 12 tasks. Duplicate tasks (case-insensitive) are dropped; each task keeps its text and deterministic keywords (tokens of three or more characters minus the stopword set).
- The session title falls back to the first task when no title is given.
- Refusals are named: goal-not-a-string, goal-empty, goal-too-many-tasks:n.

## Where it lives

src/modules/live-testing/engine/step-narration.ts (parseGoal), applied at session creation in live-testing-service.ts; POST /v1/live-testing/sessions.

## Limits, stated plainly

Parsing is deterministic splitting, not natural-language understanding. Keywords drive matching only; the task text itself is the source of truth.
