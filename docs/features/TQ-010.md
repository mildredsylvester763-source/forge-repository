# TQ-010: Hand back to the AI

## Behaviour

- The owner can hand a session back to the AI only from manual control; the session returns to running and the AI resumes driving.
- Refusals are named: session-not-found:x for anyone but the owner, session-handback-refused:status when the session is not in manual control.

## Where it lives

src/modules/live-testing/engine/session-lifecycle.ts (canHandBack), applied in live-testing-service.ts; POST /v1/live-testing/sessions/hand-back.

## Limits, stated plainly

Handing back resumes the state machine only. Steps taken during manual control are already recorded as ordinary steps; there is no replay of them.
