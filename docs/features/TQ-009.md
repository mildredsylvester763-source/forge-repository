# TQ-009: Manual takeover

## Behaviour

- The owner can take manual control of a session only while it is running or paused; the session moves to manual and the AI stops driving.
- Refusals are named: session-not-found:x for anyone but the owner, session-control-refused:status when the state cannot be taken over (manual, planned or terminal).

## Where it lives

src/modules/live-testing/engine/session-lifecycle.ts (canTakeControl), applied in live-testing-service.ts; POST /v1/live-testing/sessions/control.

## Limits, stated plainly

Takeover is a state change with an event, not an input grabber. Capturing real user input is the front end's job.
