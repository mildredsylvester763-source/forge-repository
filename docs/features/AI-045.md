# AI-045: Per-workspace model selection and pinning

## Behaviour

- A workspace pins one version per model. Re-pinning records switchedFrom and is idempotent (duplicate: true). Resolve answers pinned first, then the caller's fallback, and always says which (source: pinned / fallback).
- Tier gating: a model tier outside the plan's tiers is refused (pin-tier-denied). Unknown versions and models without any versions are refused by name (pin-unknown-version, pin-no-versions). Unpinning a workspace that never pinned is refused naming the workspace (unpin-not-pinned).
- Pins are fingerprinted (pin_ prefix) per workspace and model.

## Where it lives

src/modules/ai-training/engine/model-access-engine.ts (pure), reached through POST /v1/ai-training/access/pin, /v1/ai-training/access/unpin and /v1/ai-training/access/resolve.

## Limits, stated plainly

- Pinning is per user workspace in this build. Shared team-level pinning waits for the workspaces section.
