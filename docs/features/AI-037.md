# AI-037: Quantization and compression pipeline

## Behaviour

- Plans are per-method: int8 quarters the weights (sizeFactor 0.25, estimated quality loss 0.01), int4 cuts harder (estimated loss 0.03). The estimated loss is compared against the caller's quality budget, and a plan that would degrade beyond the budget is refused by name (quantization-quality-budget-exceeded), never silently shipped.
- Honest quantization needs calibration data: fewer than 32 samples is refused (quantization-insufficient-samples). Unknown methods are refused (quantization-unknown-method).

## Where it lives

src/modules/ai-training/engine/model-serving-engine.ts (pure), reached through POST /v1/ai-training/serving/quantize.

## Limits, stated plainly

- The quality loss is an estimate per method, not a measured one on the caller's actual weights.
