# TQ-017: Auto bug report assembly

## Behaviour

- The latest finding plus the recorded step narrations assemble into one structured, shareable bug report: title, severity label (trivial, minor, major, critical, blocker), reproduction lines (every step narration in order plus the finding's own repro line), an environment line (platform, environment, safe mode on or off), evidence, suspected commit and a deterministic dedupe key (sessionId, severity, normalized title).
- A session with no findings is refused with bugreport-none. Malformed findings are refused with bugreport-severity-invalid:n, bugreport-title-empty or bugreport-suspected-commit-invalid.

## Where it lives

src/modules/live-testing/engine/bug-report.ts (pure), reached through POST /v1/live-testing/sessions/bug-report.

## Limits, stated plainly

The report is assembled from recorded facts only. It never invents reproduction steps the session did not record.
