# AI-017: Honest experiment tracking

## Behaviour

- Metric series must be step-ordered and unique with finite losses; refusals named: metrics-step-disorder, metrics-invalid-loss, metrics-invalid-eval.
- Comparing two runs prefers eval score when both have one, otherwise final loss (lower is better); margins round to a millionth so floating point noise never surfaces in a verdict a human reads.
- Refusals named: compare-missing-run, compare-invalid-loss.

## Where it lives

src/modules/ai-training/engine/training-run-engine.ts (pure), reached through POST /v1/ai-training/runs/metric and POST /v1/ai-training/runs/compare.

## Limits, stated plainly

Best eval score is the maximum ever seen, not the last step. A run with no metrics cannot be compared, by design, not by accident.
