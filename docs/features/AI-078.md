# AI-078: Execution sandbox

## Behaviour

- Every agent action runs workspace-only: file writes must start with /workspace/.
- Network is denied by default with a per-host egress allowlist.
- Timeouts are bounded between 1 and 600 seconds (default 30).
- Destructive shell commands are refused from a denylist.
- Malformed input is refused by name: sandbox-tool-missing, sandbox-tool-unknown:x, sandbox-timeout-invalid:x, sandbox-command-missing, sandbox-command-forbidden:x, sandbox-egress-host-missing, sandbox-egress-allowlist-invalid, sandbox-egress-denied:host, sandbox-path-missing, sandbox-path-outside-workspace:path.

## Where it lives

src/modules/orchestrator/engine/execution-sandbox.ts (pure), reached through POST /v1/orchestrator/sandbox.

## Limits, stated plainly

This is the policy verdict layer: it decides what may run, it does not itself create an operating-system sandbox. The real isolation runs on the execution hosts.
