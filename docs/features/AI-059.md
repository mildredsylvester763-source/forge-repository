# AI-059: Citation tracking

## Behaviour

- Every web-derived claim must cite an https source; claims are whitespace normalized, so binding the same claim to the same source is idempotent and returns the existing citation with reused set.
- An optional source title (500 characters) and quote (5000 characters) travel with the citation; the claim itself is capped at 5000 characters.
- Refusals are named: citation-empty-claim, citation-too-short, citation-missing-source, citation-missing-scheme, citation-insecure-scheme, citation-missing-host, citation-claim-too-long, citation-title-too-long, citation-quote-too-long.

## Where it lives

src/modules/web-search/engine/citation.ts (pure), reached through POST /v1/web-search/citations, GET /v1/web-search/citations and POST /v1/web-search/citations/list.

## Limits, stated plainly

Idempotency is per user, normalized claim and source url; two users citing the same claim get separate records. There is no deduplication across different urls for the same underlying article, and nothing verifies the source actually contains the claim.
