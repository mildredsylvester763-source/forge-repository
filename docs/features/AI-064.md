# AI-064: Hybrid three-lane workspace search

## Behaviour

- Three named lanes: keyword, vector and graph. The keyword lane scores term coverage, the vector lane hashes terms into 64 dimensions with FNV-1a and compares by cosine, and the graph lane propagates the best keyword score of each linked document.
- Each lane is min-max normalized across the candidate set, then fused as a weighted sum with default weight 1 per lane.
- Refusals are named: hybrid-query-missing, hybrid-lanes-not-array, hybrid-lanes-empty, hybrid-lane-unknown, hybrid-weights-invalid (weights must be finite, not negative, and sum above zero).

## Where it lives

src/modules/workspace-retrieval/engine/hybrid-search.ts (pure), reached through GET /v1/workspace-retrieval/hybrid/lanes and POST /v1/workspace-retrieval/hybrid/search.

## Limits, stated plainly

The vector lane is a hash trick, not a learned embedding: it sees shared tokens, not meaning. Graph propagation is one hop only, and no reranking happens here.
