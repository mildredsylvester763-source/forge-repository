# AI-011: Creative works

## Behaviour

- Creative works (manhwa, music, voice) enter the registry only with the creator's consent on record (workspace default, dataType creative-work, AI-002); without it registration is refused with creative-consent-required.
- Every work is born pending. Approval and rejection are decisions; publication requires approval (creative-unapproved otherwise) and is terminal. Rejected and published works never move again: every operation on them is refused with creative-terminal-state.
- Registration is idempotent by (creator, medium, title): the same triple returns the existing work with duplicate true and nothing is appended.
- Revisions attach to approved works only, numbered per work (crev_cr_1_1, crev_cr_1_2), each with its own fingerprint.

## Where it lives

src/modules/training-data/engine/creative-engine.ts (pure), reached through POST /v1/training-data/creative/register, /approve, /reject, /publish, /revise and /list.

## Limits, stated plainly

Consent is checked per creator name against the owner's registry, not proven per creator. Revoking consent does not delete registered works; it only stops new registrations. A published work keeps its revisions frozen; a revision is never edited, only joined by the next one.
