# AI-081: Task control state machine

## Behaviour

- States: running, paused, cancelled, completed, failed, overtaken. Commands: pause, resume, cancel, takeover.
- Six legal transitions: running accepts pause, cancel and takeover; paused accepts resume, cancel and takeover.
- Terminal states (cancelled, completed, failed, overtaken) accept no commands at all.
- Everything else is refused by name: task-state-unknown:zombie, task-command-unknown:rewind, task-invalid-transition:completed:pause.

## Where it lives

src/modules/task-runtime/engine/task-control.ts (pure), reached through POST /v1/tasks/command, GET /v1/tasks/states and GET /v1/tasks/commands.

## Limits, stated plainly

The engine judges one transition at a time. Persisting the resulting state is the journal job (AI-082), not the command engine job.
