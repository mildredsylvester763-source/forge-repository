# AI-008: Human labeling and Borda tally

## Behaviour

- A label is one labeler's ranking of a batch's candidates, best first. Each labeler labels a batch exactly once; a second ranking is a conflict refused by name, never a silent merge.
- Aggregation is a Borda count: on a ballot with m ranked candidates, the candidate at rank i earns m - 1 - i points. Totals order the result, ties break by candidate name ascending, so the outcome is deterministic.
- The tally counts only the named batch and reports the number of labelers behind it. A batch with no labels is refused with labeling-no-labels.
- Rankings must be non-empty lists of non-empty names; anything else is refused with the named reason.

## Where it lives

src/modules/training-data/engine/labeling-engine.ts (pure), reached through POST /v1/training-data/labeling/submit, POST /v1/training-data/labeling/borda and POST /v1/training-data/labeling/list.

## Limits, stated plainly

Borda counts ballots, not expertise: every labeler weighs the same. A ballot listing the same candidate twice would earn points twice; the engine does not silently deduplicate a labeler's mistake.
