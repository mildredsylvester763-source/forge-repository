# AI-040: Response caching and prompt-prefix reuse

## Behaviour

- Exact hits replay the cached answer; prefix hits reuse the longest cached prefix and save half of the reused input cost. Entries from other models are invisible - zero trust between models.
- Admits are idempotent: a repeated admit answers duplicate: true and evicts nothing. At capacity the least-recently-used non-pinned entry is evicted (ties broken deterministically); pinned entries are never evicted, and a full all-pinned pool is refused by name (cache-full-pinned).

## Where it lives

src/modules/ai-training/engine/model-operations-engine.ts (pure), reached through POST /v1/ai-training/ops/cache/admit and /v1/ai-training/ops/cache/lookup.

## Limits, stated plainly

- Reuse is exact and prefix-only. There is no near-duplicate or semantic matching, so a one-word difference is a miss.
