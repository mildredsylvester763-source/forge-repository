## Why implementation is blocked

Encryption at rest is not only an algorithm choice. It requires a defined key hierarchy, KMS or secret source, rotation/re-encryption strategy, backup/restore behavior, service identity/access boundary and recovery procedure. Implementing a custom envelope or key store before those decisions would violate the repository's explicit owner boundary.

1. Approve the key source (managed KMS or owner-managed key) and service access model.
2. Define key IDs, rotation cadence, old-key retention, re-encryption and rollback.
3. Define database-field/file encryption scope and backup encryption/decryption ownership.
4. Define disaster recovery, key-loss recovery and separation of duties.
5. Supply the exact Part 01 CO-018 acceptance wording.
