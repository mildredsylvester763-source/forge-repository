# TQ-001: Live testing session lifecycle

## Behaviour

- A live agent testing session moves through planned, running, paused, manual, completed, failed and cancelled. Legal transitions: planned to running or cancelled; running to paused, manual, completed, failed or cancelled; paused to running, manual or cancelled; manual to running, paused or cancelled. The three terminal states never change again.
- A session is created with a platform, an environment, a safe mode decision, a parsed goal and an optional persona; it starts as planned. Starting records startedAt; completing, failing or cancelling records endedAt.
- Illegal moves are refused by name: session-unknown-status:x, session-terminal:x, session-transition-illegal:from:to.

## Where it lives

src/modules/live-testing/engine/session-lifecycle.ts (pure), reached through POST /v1/live-testing/sessions (create) and POST /v1/live-testing/sessions/start, /pause, /resume, /complete, /fail, /cancel.

## Limits, stated plainly

The lifecycle engine validates state changes only. It does not drive a browser or device; the platform capability engine does that.
