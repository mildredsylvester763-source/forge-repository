# AI-086 - Self-critique pass before presenting results

Catalog row (Part 01 With Plans): "Self-critique pass before presenting results" - Plan from: Free, Engine: General, no pass needed.

## What it is
A result is never presented without a critique pass. Every item is validated by name, and a result that names no caveat and no uncertainty is sent back for revision with the issue `no-caveat-or-uncertainty` - honest limits are not optional.

## Engine
`src/modules/ai-training/engine/self-critique-engine.ts` - pure.
- `runSelfCritique({ resultId, summary, items })` - a non-empty result id and summary, a non-empty item list. Each item is a kind (fact, caveat, uncertainty, action) with non-empty text. The verdict is `present` only when at least one caveat or uncertainty is named, else `revise`. The report carries an `sc_` fingerprint and never mutates the caller input.

Refusals: `critique-no-result-id`, `critique-no-summary`, `critique-no-items`, `critique-item-invalid:<i>`, `critique-kind-invalid:<kind>`, `critique-empty-text:<i>`.

## Routes (POST, session required, gate: free)
- `/v1/ai-training/critique/run` - 200, the report (verdict, issues, fingerprint) and its createdAt

## Honest state
Reports live in an in-memory session Map (the streaming-sessions precedent): a restart clears them, nothing is persisted yet. The engine judges only what the caller submits - it never invents confidence.
