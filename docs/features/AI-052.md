# AI-052: Token, cost, and latency accounting per provider

## Behaviour

- Accounting sums requests, failures, the honest error rate, tokens in and out, real cost from the provider's declared prices, and average latency over successful calls. Cost per 1k tokens comes from the declared prices, never invented.
- Unknown providers are refused (provider-not-found). Numbers come only from calls recorded through this gateway.

## Where it lives

src/modules/ai-training/engine/model-gateway-engine.ts (pure), reached through POST /v1/ai-training/gateway/accounting.

## Limits, stated plainly

- Usage that bypassed the gateway is invisible to it. The accounting is exactly as complete as the call recording.
