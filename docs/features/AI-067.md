# AI-067: Fact versus claim separation

## Behaviour

- Statements are separated into facts and claims: a statement corroborated by two or more distinct source ids is a fact, anything else stays a claim.
- Repeated source ids are deduplicated per statement, so the same source twice still counts once and never fakes corroboration.
- Limits: at most 200 statements per request. Refusals are named: statements-empty, statements-count-invalid, statement-text-missing, statement-sources-missing, statement-source-blank.

## Where it lives

src/modules/search-integrity/engine/fact-claims.ts (pure), reached through POST /v1/search-integrity/facts.

## Limits, stated plainly

This is corroboration counting, not truth checking. A fact here means independently sourced, and it is only as trustworthy as the id discipline of whoever supplies the sources.
