# AI-075: Plan preview

## Behaviour

- Every plan shows step count, files touched, risk class and estimated cost before it is approved.
- Risk and cost are pinned per action, so previews are deterministic: search 400/low, write 1200/medium, run 600/high, verify 300/low, present 200/low.
- High risk always requires approval.
- Malformed input is refused by name: preview-steps-empty, preview-step-action-missing, preview-step-action-unknown:x.

## Where it lives

src/modules/orchestrator/engine/plan-preview.ts (pure), reached through POST /v1/orchestrator/preview; plan create and edit responses embed its verdict.

## Limits, stated plainly

Costs are planning estimates in credits, not billing amounts. Files touched are what steps declare, not what execution later touches.
