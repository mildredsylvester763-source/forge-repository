# AI-073: Intent classification

## Behaviour

- Incoming text is scored against a fixed catalog (question, command, creation, analysis, comparison, conversation) by word-boundary keyword rules.
- The best intent wins, ties break in catalog order, and confidence is the share of keyword hits owned by the winner.
- An optional allowlist restricts routing to approved intents; routing outside it is refused by name.
- Malformed input is refused by name: intent-text-missing, intent-text-too-long, intent-allowlist-invalid, intent-allowlist-unknown:x, intent-no-match, intent-not-allowed:x.

## Where it lives

src/modules/orchestrator/engine/intent-classification.ts (pure), reached through POST /v1/orchestrator/intent and GET /v1/orchestrator/intents. Plan creation falls back to it when no explicit intent is given.

## Limits, stated plainly

Keyword scoring is deterministic but shallow: it routes, it does not understand. Unroutable text becomes the unclassified intent instead of a guess.
