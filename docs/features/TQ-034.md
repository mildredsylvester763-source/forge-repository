# TQ-034: Property-based test generation

## Behaviour

- A property suite is reproducible by construction: the plan carries a name, runs (1 to 1000, default 100), seed (default 42) and a repro string property:name seed:s runs:r.
- Seeded case streams come from the shared mulberry32 PRNG: generateIntCases produces inclusive min..max integers, generateStringCases produces strings of length 1..maxLen over a custom alphabet; shrinkInt binary-searches the smallest failing input for upward-closed predicates and returns the input unchanged when it does not fail.
- Malformed input is refused by name: property-name-missing, property-name-too-long, property-runs-invalid:n, property-seed-invalid:n, property-range-invalid:min:max, property-length-invalid:n.

## Where it lives

src/modules/test-generation/engine/property-based.ts (pure), reached through POST /v1/test-generation/property/plan. The stored suite carries the seed and an FNV-1a checksum of the repro string.

## Limits, stated plainly

Shrinking assumes upward-closed predicates (once a value fails, every larger value fails); other failure shapes shrink to their starting point, not to a true minimum.
