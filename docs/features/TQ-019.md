# TQ-019: Live device catalog

## Behaviour

- GET /v1/live-testing/devices returns the catalog of twelve named devices and six pinned networks. Devices span web (chrome-desktop, firefox-desktop, safari-mac, edge-windows style entries), android (pixel-5, galaxy-s22, low-end-android), ios (iphone-13, ipad-9, low-end-iphone) and desktop.
- low-end-android and low-end-iphone are marked low end with a CPU throttle of 4; every other device throttles at 1.
- Networks carry honest numbers: offline 0 kbps and 0 ms, slow-2g 50/2000, slow-3g 400/2000, fast-3g 1500/150, 4g 9000/100, wifi 30000/40 (downlink and latency).
- The route requires a signed-in user.

## Where it lives

src/modules/live-testing/engine/device-profile.ts (pure) through src/modules/live-testing/routes.ts, GET /v1/live-testing/devices.

## Limits, stated plainly

The catalog is static and simulated. It does not rent or drive real phones; the real device farm flagged in the catalog notes stays out of scope.
