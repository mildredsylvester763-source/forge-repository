# AI-038: On-device small models for offline use

## Behaviour

- A bundle pairs quantized bytes with device memory and reports headroom in bytes and as a ratio. A bundle that would not fit is refused by name (bundle-exceeds-device-memory).
- The runtime must be a real offline runtime (llama.cpp and siblings). An "offline" bundle that secretly calls a server is a privacy violation, so unknown or online runtimes are refused (bundle-no-offline-runtime).

## Where it lives

src/modules/ai-training/engine/model-serving-engine.ts (pure), reached through POST /v1/ai-training/serving/bundle.

## Limits, stated plainly

- Device memory is declared by the caller. There is no real device profiling yet, so a "fits" answer is a plan, not a guarantee.
