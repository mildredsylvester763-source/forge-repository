# AI-071: Fenced fetched content and injection tripwire

## Behaviour

- Fetched content is wrapped in explicit fences, opening and closing, so downstream consumers can tell untrusted text from instructions.
- Smuggled fences already inside the content are stripped before wrapping, so a fetched page cannot close the fence early.
- The scanner checks seven named markers case-insensitively, including the fence itself, and reports every finding by marker and index, sorted by index. Clean content returns clean true; findings quarantine.
- Refusal is named: injection-content-missing for blank input.

## Where it lives

src/modules/search-integrity/engine/injection-defense.ts (pure), reached through POST /v1/search-integrity/injection/wrap and POST /v1/search-integrity/injection/scan.

## Limits, stated plainly

Scanning is a tripwire, not a security boundary, exactly as OWASP LLM01 intends the fence to be. Markers can be paraphrased or encoded, and no model-based detector runs here.
