# TQ-013: Custom test personas

## Behaviour

- A user can create custom personas beside the builtin catalog: a name (trimmed, lowercased, unique per user and workspace), traits, a checklist and a pace multiplier between 0.25 and 4.
- A name that collides with a builtin persona or an existing custom persona is refused with persona-duplicate:name. Custom personas are listed per workspace and can be deleted by their owner only.
- Refusals are named: persona-name-missing, persona-duplicate:x, persona-pace-invalid, persona-not-found:x.

## Where it lives

src/modules/live-testing/live-testing-service.ts (createCustomPersona, listCustomPersonas, deleteCustomPersona); POST /v1/live-testing/personas/custom, /personas/custom/list, /personas/custom/delete.

## Limits, stated plainly

Custom personas are trait vectors like the builtins: a session references one by name at creation. They carry no prose or instructions.
