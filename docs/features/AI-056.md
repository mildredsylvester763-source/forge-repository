# AI-056: Unified tool-calling and structured-output layer

## Behaviour

- Tool calls are normalized across providers: the provider must be known (unknown refused by name), the arguments must be valid JSON (toolcall-invalid-arguments), and the parsed arguments are fingerprinted (tc_ prefix).
- Output schemas are registered per schema id (fingerprint os_ prefix) and validated strictly: missing fields, wrong types and non-enum values are refused naming the field and what was expected (output-missing-field, output-wrong-type, output-not-enum). Unknown schemas are a 404 (schema-not-found).

## Where it lives

src/modules/ai-training/engine/model-gateway-ops-engine.ts (pure), reached through POST /v1/ai-training/gateway/toolcall, /v1/ai-training/gateway/schemas and /v1/ai-training/gateway/schemas/validate.

## Limits, stated plainly

- Schemas check shape, not meaning. A well-typed wrong answer still passes.
