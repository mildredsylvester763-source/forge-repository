**Implementation status:** MISSING / OWNER-BLOCKED. No desktop-specific token implementation is claimed.

- Mistral identity module and test directory listings contain no desktop-token module or desktop-token test.

## Why implementation is blocked

The repository does not define:
- The exact desktop client audience and whether a desktop credential differs from the existing opaque bearer session.
- Whether desktop device registration, per-device revocation or device attestation is required.
- Token expiry, refresh/rotation, offline grace and reauthentication semantics.
- Desktop secure-storage expectations and client platform boundaries.
- The relationship between desktop identity and tenant/workspace membership.

These are security and product semantics. Implementing a guessed JWT, refresh-token or device-registration model could create an incompatible or unsafe authentication contract.

## Safe next step

The owner must supply the exact Part 01 CO-009 wording and approve the desktop audience, token lifecycle and secure-storage contract. This does not block independent CO features; continue with the next CO feature and retain CO-009 in the approval-needed register.
