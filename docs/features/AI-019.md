# AI-019: Cost ledger with a hard budget cap

## Behaviour

- Every cost event charges a ledger; the event that would cross the budget is refused with cost-budget-exceeded naming spent, budget and step, and the ledger stays unchanged.
- Spending exactly to the cap is allowed; one unit past it is refused.
- Malformed events are refused with 400 (cost-event-invalid-step, cost-event-invalid-units); only the cap refusal is a 409 conflict.

## Where it lives

src/modules/ai-training/engine/cost-reproducibility-engine.ts (pure), reached through POST /v1/ai-training/runs/cost.

## Limits, stated plainly

Units are caller-declared credits; the ledger never sees real invoices. Refusing the write stops the app from spending more, it cannot claw back money already spent outside.
