# AI-054: Zero-retention routing for sensitive workspaces

## Behaviour

- Retention modes come from a fixed set; unknown modes are refused by name (retention-unknown-mode). Zero mode omits content entirely (contentOmitted: true, empty text) and keeps only the metadata.
- Retention-aware routing excludes providers whose retention does not satisfy the mode, names the excluded providers, and still quotes the estimated cost of what remains.

## Where it lives

src/modules/ai-training/engine/model-gateway-ops-engine.ts (pure), reached through POST /v1/ai-training/gateway/retention and /v1/ai-training/gateway/retention/route.

## Limits, stated plainly

- A provider's real retention behavior is declared, not verified. The exclusion is only as honest as the registration behind it.
