# AI-047: Models bundled into on-prem installs

## Behaviour

- A package is built only from a servable stage (beta or stable): experimental and internal versions are refused (package-not-servable). The package records the format (forge-pkg-1), the weights fingerprint and the license terms; empty license terms are refused (package-no-license).
- Re-import verifies end to end: wrong weights are refused naming both fingerprints (reimport-weights-mismatch), a quality score under the gate is refused (reimport-quality-gate), and an unaccepted license is refused (reimport-license-not-accepted). Unknown packages are a 404 (package-not-found).
- Packages are fingerprinted (xpk_ prefix) so an on-prem install can be matched back to its source version.

## Where it lives

src/modules/ai-training/engine/model-access-engine.ts (pure), reached through POST /v1/ai-training/access/packages and /v1/ai-training/access/packages/verify.

## Limits, stated plainly

- Verification trusts the fingerprint, not a re-run of the eval suite. The bytes are never in the package record itself; they travel separately.
