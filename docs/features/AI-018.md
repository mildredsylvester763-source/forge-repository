# AI-018 - Experiment tracking: configs, metrics, loss curves, comparisons

Catalog row (Part 01 With Plans): "Experiment tracking: configs, metrics, loss curves, comparisons" - Plan from: Free, Engine: General, no pass needed. Forge machinery: internal, never sold.

## What it is
An operator defines a training experiment with a config and a named metric list, logs metric points as training proceeds, reads back the loss curves sorted by step, and compares two experiments on one metric with an honest delta. Pure, deterministic, named refusals. Distinct from the AI-029 in-product A/B experiments (people variants) and from training-run metrics: this tracks the experiments the operator defines.

## Engine
`src/modules/ai-training/engine/experiment-tracking-engine.ts` - pure.
- `defineTrackedExperiment({ experimentId, config, metrics })` - a non-empty id, a non-empty config (string, finite number or boolean values only) and a non-empty metric list without duplicates. Returns an `ext_` fingerprint over the id, the sorted config keys and the metrics.
- `logTrackedPoint(experiment, { step, metric, value })` - the metric must be declared, the step a non-negative integer, the value finite. Returns the new experiment record with the point appended; the caller record is never mutated.
- `trackedCurves(experiment, metric?)` - every metric (or one) as a curve, points copied and sorted by step, then value.
- `compareTrackedExperiments(a, b, metric)` - the last point (highest step) of each experiment for the metric, with counts and the delta (b minus a, 4 decimal places).

Refusals: `experiment-tracking-no-id`, `experiment-tracking-no-config`, `experiment-tracking-config-invalid:<key>`, `experiment-tracking-no-metrics`, `experiment-tracking-metric-invalid:<i>`, `experiment-tracking-metric-duplicate:<name>`, `experiment-tracking-unknown-metric:<name>`, `experiment-tracking-bad-step`, `experiment-tracking-bad-value`, `experiment-tracking-compare-no-metric`, `experiment-tracking-compare-empty:<metric>`.

## Routes (all POST, session required, gate: internal)
- `/v1/ai-training/tracking/define` - 201, the experiment and its createdAt
- `/v1/ai-training/tracking/point` - 200, the logged point (409 duplicate, 404 tracked-experiment-not-found)
- `/v1/ai-training/tracking/curves` - 200, the curves for all metrics or one
- `/v1/ai-training/tracking/compare` - 200, the last values, counts and delta

## Honest state
Experiments live in an in-memory session Map (the streaming-sessions precedent): a restart clears them, nothing is persisted yet. Persistence lands when the owner asks for it.
