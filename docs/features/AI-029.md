# AI-029: Consent-gated experiments with honest statistics

## Behaviour

- Experiments are two or more variants with integer split percents summing to 100; consentGranted must be literally true, there is no default, no opt-out, no silent experiment.
- Assignment is deterministic: a hash of experiment and subject walked against cumulative splits, so the same subject lands in the same arm forever, across restarts.
- Tallies report per-variant totals and rates; below the samples floor the verdict is insufficient-samples; otherwise a pooled two-proportion z test with critical value 1.96 decides variant-wins or inconclusive.
- Refusals named: experiment-no-id, experiment-no-consent, experiment-single-variant, experiment-invalid-split, experiment-invalid-split-total, assignment-consent-declined, assignment-experiment-inactive, outcome-not-assigned, outcome-duplicate.

## Where it lives

src/modules/ai-training/engine/product-experiment-engine.ts (pure), reached through POST /v1/ai-training/experiments, POST /v1/ai-training/experiments/assign, POST /v1/ai-training/experiments/outcome and POST /v1/ai-training/experiments/tally.

## Limits, stated plainly

The z test compares the top two arms only; more arms would need multiple-comparison correction, not built. One boolean outcome per subject. Sequential peeking inflates error and the engine does not stop you.
