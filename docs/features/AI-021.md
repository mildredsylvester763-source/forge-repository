# AI-021: Versioned benchmark suites

## Behaviour

- Suites are named, versioned and content-fingerprinted (suitefp prefix); version is metadata, identical content fingerprints identically, which is how re-versioning the same content is refused.
- The first version must be 1 and later versions must be latest plus one; violations are 409 conflicts named eval-suite-version-gap and eval-suite-unchanged-content.
- Refusals named: suite-no-id, suite-invalid-version, suite-no-kind, suite-no-cases, suite-duplicate-case, suite-case-invalid-domain, suite-case-no-criteria.

## Where it lives

src/modules/ai-training/engine/eval-gate-engine.ts (pure), reached through POST /v1/ai-training/eval/suites and POST /v1/ai-training/eval/suites/get.

## Limits, stated plainly

Fingerprints are structural: two semantically identical suites with different case ids are different content. There is no import from external benchmark formats.
