# AI-005: Immutable dataset snapshots

## Behaviour

- A snapshot freezes eligible, non-deleted assets into item identities with a content fingerprint (dsfp prefix) over canonical per-item serialization; identical content always fingerprints identically.
- Items carry consent, classification, quality and tags. Snapshots are frozen evidence, never edited in place.
- Refusals named: dataset-name-missing, dataset-no-items, dataset-item-without-consent, dataset-invalid-quality, dataset-unchanged-content.

## Where it lives

src/modules/ai-training/engine/dataset-snapshot.ts (pure), reached through POST /v1/ai-training/datasets and POST /v1/ai-training/datasets/get.

## Limits, stated plainly

The fingerprint covers identity fields and tags, not the bytes of the underlying media. Two datasets with different file contents but identical metadata fingerprint the same.
