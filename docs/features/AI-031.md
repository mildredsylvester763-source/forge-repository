# AI-031: Eval trend dashboards

## Behaviour

- Samples record a metric, a bucket and a score; the same bucket with the same score is idempotent, and a different score is a 409 conflict named trend-conflicting-score.
- The trend sorts buckets, computes deltas rounded to a millionth, and flags improving, flat or degrading against the declared threshold; degraded buckets are listed.
- Refusals named: trend-no-samples, trend-invalid-degrade-threshold, trend-invalid-score.

## Where it lives

src/modules/ai-training/engine/product-experiment-engine.ts (pure), reached through POST /v1/ai-training/trend/samples and POST /v1/ai-training/trend/build.

## Limits, stated plainly

Buckets are opaque strings, so ordering is lexicographic; 2027-10 sorts before 2027-2. One score per bucket means points, not distributions.
