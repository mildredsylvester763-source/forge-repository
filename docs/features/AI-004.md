# AI-004: PII and secret scrubbing before training eligibility

## Behaviour

- Every non-empty description is scrubbed before storage: emails, phones, government ids, bearer tokens, JWTs, Stripe and AWS keys, Google API keys, private key blocks and assigned credentials.
- Redaction is destructive: matched bytes are replaced with [REDACTED] and the original never survives anywhere. Findings are reported per kind with counts plus a total.
- Refusals named: scrub-not-a-string, scrub-empty-text, scrub-text-too-large.

## Where it lives

src/modules/ai-training/engine/scrub-engine.ts (pure); scrubbing runs inside asset creation on POST /v1/ai-training/assets.

## Limits, stated plainly

Pattern matching, not understanding. An unusual secret shape can slip through, so raw assets must stay out of training regardless. Findings describe what was matched, not proof the text is now safe.
