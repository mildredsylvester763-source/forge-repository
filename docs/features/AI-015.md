# AI-015 - Preference tuning pipelines (RLHF, DPO style)

Catalog row (Part 01 With Plans): "Preference tuning pipelines (RLHF, DPO style)" - Plan from: Free, Engine: General, no pass needed. Forge machinery: internal, never sold.

## What it is
A user defines a preference tuning pipeline over chosen/rejected answer pairs, picks a method (RLHF or DPO), sets hyperparams, and walks the pipeline stage by stage to an honest verdict. The engine is pure and deterministic: named refusals, deduped pairs, method-specific stages, fingerprinted pipelines.

## Engine
`src/modules/ai-training/engine/preference-tuning-engine.ts` - pure.
- `defineTuningPipeline({ pipelineId, method, pairs, hyperparams })` - validates the id, the method, every pair (non-empty prompt/chosen/rejected; chosen must differ from rejected) and the hyperparams (learningRate in (0,1), beta in (0,2], integer epochs 1..100). Identical pairs are deduped and counted in `duplicatesDropped`. RLHF walks collect, reward, optimize, evaluate; DPO walks prepare, optimize, evaluate.
- `advanceTuningStage(pipeline, metrics?)` - a sequential state machine. Entering `evaluate` requires metrics `{ rewardMargin, acceptanceRate }` (acceptanceRate 0..1) and returns the verdict: accepted when acceptanceRate is at least 0.6 and rewardMargin is positive, else rejected.

Refusals: `pipeline-no-id`, `pipeline-method-unknown:<method>`, `pipeline-no-pairs`, `pipeline-pair-invalid:<i>`, `pipeline-pair-identical:<i>`, `pipeline-bad-hyperparams:<field>`, `tuning-missing-metrics`, `tuning-metrics-invalid:<field>`, `pipeline-stage-invalid`.

## Routes (all POST, session required, gate: internal)
- `/v1/ai-training/tuning/define` - 201, the pipeline and its createdAt
- `/v1/ai-training/tuning/advance` - 200, the next stage (and the verdict on evaluate)
- `/v1/ai-training/tuning/status` - 200, the pipeline plus the stored verdict

## Honest state
Pipelines live in an in-memory session Map (the streaming-sessions precedent): a restart clears them, nothing is persisted yet. Persistence lands when the owner asks for it.
