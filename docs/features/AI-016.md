# AI-016 - Distillation from larger models into small deployable ones

Catalog row (Part 01 With Plans): "Distillation from larger models into small deployable ones" - Plan from: Free, Engine: General, no pass needed. Forge machinery: internal, never sold.

## What it is
A user plans a distillation from a teacher model into a strictly smaller student, supplies prompt/teacher-output samples and a quality gate, then walks the plan stage by stage to a registered (or rejected) student. Pure, deterministic, named refusals.

## Engine
`src/modules/ai-training/engine/distillation-engine.ts` - pure.
- `planDistillation({ planId, teacherModelId, teacherVersion, studentModelId, teacherParams, studentParams, samples, qualityGate })` - the student must be strictly smaller than the teacher (`distillation-student-too-large`), the quality gate strictly between 0 and 1, samples non-empty with prompt and teacherOutput. Returns the honest `compressionRatio` (student/teacher, 4 decimal places), sample fingerprints and a `dist_` fingerprint. Stages: generate, compress, evaluate, register.
- `advanceDistillationStage(plan, metrics?)` - sequential state machine. Entering `evaluate` requires `{ studentAccuracy }` (0..1); the verdict is accepted when studentAccuracy meets the quality gate. The plan completes at `register`.

Refusals: `distillation-no-plan-id`, `distillation-no-teacher`, `distillation-no-student`, `distillation-teacher-version-invalid`, `distillation-teacher-params-invalid`, `distillation-student-params-invalid`, `distillation-student-too-large`, `distillation-no-samples`, `distillation-sample-invalid:<i>`, `distillation-quality-gate-invalid`, `distillation-missing-metrics`, `distillation-metrics-invalid:studentAccuracy`, `distillation-stage-invalid`.

## Routes (all POST, session required, gate: internal)
- `/v1/ai-training/distill/plan` - 201, the plan and its createdAt
- `/v1/ai-training/distill/advance` - 200, the next stage (and the verdict on evaluate)
- `/v1/ai-training/distill/status` - 200, the plan plus the stored verdict

## Honest state
Plans live in an in-memory session Map (the streaming-sessions precedent): a restart clears them, nothing is persisted yet. Persistence lands when the owner asks for it.
