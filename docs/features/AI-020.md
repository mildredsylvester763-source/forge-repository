# AI-020: Reproducibility fingerprints

## Behaviour

- A run fingerprint pins dataset fingerprint, code version, seed, environment and hyperparameters; identical config always fingerprints identically (runfp prefix).
- Refusals named: run-config-missing, run-config-no-dataset, run-config-invalid-seed, run-config-no-code-version, run-config-no-environment.
- Two runs with the same fingerprint are the same experiment by content truth, not by id.

## Where it lives

src/modules/ai-training/engine/cost-reproducibility-engine.ts (pure), computed on POST /v1/ai-training/runs.

## Limits, stated plainly

The pin is only as honest as the declared code version and environment; the engine cannot verify a commit sha. Hyperparameters fingerprint as canonical JSON, so key order never matters.
