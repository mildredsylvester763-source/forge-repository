# AI-039: Model routing: cheap model first, escalate when confidence is low

## Behaviour

- Models are sorted by cost per 1k tokens; the cheapest one that can hold the prompt is primary and the rest form an escalation chain with a named worst-case cost.
- A cost cap that truncates the chain is flagged (truncatedByCap), never silent. A cap below the primary's own cost is refused outright (routing-cap-below-primary).
- Confidence threshold defaults to 0.7: below it the request escalates. Inactive models, duplicates, negative costs and a prompt no model can hold are all refused by name (routing-inactive-model, routing-duplicate-model, routing-invalid-cost, routing-prompt-too-long).

## Where it lives

src/modules/ai-training/engine/model-serving-engine.ts (pure), reached through POST /v1/ai-training/serving/route.

## Limits, stated plainly

- Confidence is supplied at runtime by the caller. This engine plans the chain; it does not read the model's mind.
