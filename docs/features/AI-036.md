# AI-036: Inference serving with autoscaling and GPU pooling

## Behaviour

- Little's law sizes the pool: in-flight = rps x latency, replicas = ceil(in-flight / (concurrency x target)). Scale up is immediate; scale down is one cautious step, never a cliff.
- GPUs are assigned round-robin over the pool sorted by id, so the assignment is deterministic and reproducible.
- Refusals named: scaling-no-model, scaling-invalid-rps, scaling-invalid-latency, scaling-invalid-concurrency, scaling-invalid-target, scaling-no-gpu-pool, scaling-invalid-gpu, scaling-invalid-slots, scaling-replicas-capped (the cap is never crossed silently), scaling-pool-exhausted (refused, not under-provisioned).
