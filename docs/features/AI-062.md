# AI-062: Version-pinned library docs search

## Behaviour

- A pinned catalog of three libraries with explicit versions: react (18.2.0, 19.0.0), express (4.18.2), typeorm (0.3.17, 0.3.20).
- A query AND-matches over symbol, kind and summary, case-insensitive; only rows containing every term are returned, in catalog order.
- Validation is ordered and named: docs-library-missing, docs-library-unknown, docs-version-missing, docs-version-unknown, docs-query-missing. Library and version are trimmed and lowercased before matching.

## Where it lives

src/modules/workspace-retrieval/engine/library-docs.ts (pure), reached through GET /v1/workspace-retrieval/library/catalog and POST /v1/workspace-retrieval/library/search; every route requires a signed-in user.

## Limits, stated plainly

The catalog is a hand-pinned snapshot, not live documentation. There is no fuzzy matching and no ranking: a query with one wrong term returns an honest empty list rather than a guess.
