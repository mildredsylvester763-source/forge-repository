# AI-048: Provider-neutral gateway for outside models

## Behaviour

- Providers are registered with cost per 1k tokens in and out, a max token ceiling and retention days. Invalid costs, token ceilings and retention values are refused by name (gateway-provider-invalid-cost, gateway-provider-invalid-tokens, gateway-provider-invalid-retention).
- Routing sorts by output cost, builds a cheap-first chain and names the estimated cost. No active providers is refused (gateway-no-active-providers); a prompt no provider can hold is refused with the token total (gateway-no-capable-provider).

## Where it lives

src/modules/ai-training/engine/model-gateway-engine.ts (pure), reached through POST /v1/ai-training/gateway/providers, /v1/ai-training/gateway/providers/list and /v1/ai-training/gateway/route.

## Limits, stated plainly

- Providers are declarations, not live endpoints. The gateway plans and accounts; it does not open connections to the outside service itself.
